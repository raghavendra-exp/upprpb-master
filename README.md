## 🎯 Core Features & Architecture

### 1. Separate Recruitment Cadres
* **UP Police Constable:** Civil Police & PAC (60,244 vacancies, 150 Qs, 300 Marks, -0.5 Negative Marking, PET Running: Male 4.8 km in 25 min, Female 2.4 km in 14 min).
* **UP Police Sub-Inspector (SI):** Civil Police SI & Platoon Commander PAC (4,543 vacancies, 160 Qs, 400 Marks, Sectional 35% & Aggregate 50% cutoff, PET: Male 4.8 km in 28 min, Female 2.4 km in 16 min).
* **UP Police Computer Cadre:** Computer Operator Grade-A (985 posts, 160 Qs, 200 Marks, CS Core 80 Qs / 100 Marks, Typing: Hindi 25 wpm / English 30 wpm).
* **UP Police Radio Police:** Head Operator, Assistant Operator, Workshop Hand (2,430 posts, 160 Qs, 400 Marks, Physics & Electronics emphasis, 50% sectional cutoff).
* **Ministerial / Clerical Cadre:** Police ASI Clerk, ASI Accounts, SI Confidential (921 posts, 200 Qs, 400 Marks, Speed Typing & Shorthand).
* **Jail Police:** Jail Warder.
* **Fire Service:** Fireman.
* **Motor Transport:** Police Driver & MT Technical trade.

### 2. Old Law ↔ New Law Criminal Code Converter (Essential for SI Aspirants)
Interactive converter tracking the landmark transition effective 1 July 2024:
* **Bharatiya Nyaya Sanhita (BNS) 2023** ↔ **Indian Penal Code (IPC) 1860** (e.g., Murder: IPC 302 ➔ BNS 103, Hit-and-Run: BNS 106(2), Rape: IPC 376 ➔ BNS 64, Cheating: IPC 420 ➔ BNS 318(4), Snatching: BNS 304).
* **Bharatiya Nagarik Suraksha Sanhita (BNSS) 2023** ↔ **Code of Criminal Procedure (CrPC) 1973** (e.g., FIR & Zero FIR: CrPC 154 ➔ BNSS 173 with 3-day e-FIR rule; Arrest: CrPC 41 ➔ BNSS 35; Police Remand: CrPC 167 ➔ BNSS 187; Mandatory Forensics & Videography: BNSS 105 & 176(3)).
* **Bharatiya Sakshya Adhiniyam (BSA) 2023** ↔ **Indian Evidence Act (IEA) 1872** (Admissibility of electronic records: Section 65B IEA ➔ Section 61, 62 & 63 BSA).

### 3. 1,244+ Question Bank & Verified PYQs
* **100% Quality Controlled:** Every question includes bilingual text (Hindi + English), 4 options, verified answer index, detailed explanation, topic, and difficulty.
* **Separation of Verified PYQs:** Shift-wise past paper questions (Constable 2018, 2019, 2024 Re-Exam; SI 2021 CBT; Radio 2024; Computer Operator 2021) are strictly demarcated from original practice questions.
* **Subject Breakdown:** UP GK (150 Qs), Hindi (110 Qs), Polity (105 Qs), Law & Mool Vidhi (100 Qs), Maths (100 Qs), Reasoning (100 Qs), Science (102 Qs), History (102 Qs), Geography (101 Qs), Economy (101 Qs), Computer (73 Qs), Current Affairs (100 Qs).

### 4. Practice & Mock Test Engine
* **Practice Modes:** Quick 10, Topic 20, Chapter 30, Subject 50, Mixed 100, Verified PYQs Only, Bookmarks, and Error Notebook.
* **Official Timed Mocks:** Live countdown timer, Question Palette (Answered, Not Answered, Marked for Review), negative marking calculation, sectional cutoff analysis, and instant scorecards.

### 5. Typing Speed Simulator
* Realistic typing simulator for **ASI Clerk** (Hindi Inscript 25 wpm, English 30 wpm, 85% accuracy) and **ASI Accounts** (Hindi 15 wpm) with real-time WPM, CPM, errors, and qualifying badge.

### 6. Physical Standards & Running Tracker
* PST height/chest/weight requirements.
* RFID timed running benchmarks (Male: 4.8 km in 25 min; Female: 2.4 km in 14 min).
* Built-in local storage **Running Tracker** with pace calculator (min/km), split logs, and progress metrics.
* 8-Week progressive endurance training guide.

### 7. Authorized Book Library & NCERT Mappings
* Curated reference books from *Youth Competition Times (YCT), Kiran Prakashan, Lucent, Aditya Publication, Arihant, and Pariksha Manthan*.
* **Zero Piracy:** All links direct exclusively to authorized publishers, NCERT, and recognized bookstores.
* Direct mapping to **NCERT Class 6–12** chapters (1857 Revolt, Fundamental Rights, Rivers, Physical Sciences).

### 8. Spaced Repetition Flashcards & Error Notebook
* **Active Recall 3D Flip Flashcards** with Known, Unknown, and Review Later classifications.
* **Scientific Spaced Repetition Cycle:** 1-day, 3-day, 7-day, 15-day, and 30-day revision schedules.
* **Automatic Error Notebook:** Any wrong answer during practice or mocks is automatically catalogued for targeted re-testing.

### 9. 10-Level Roadmap & Study Plan Generator
* 10-Level Zero-to-Master progression (Level 0: Recruitment Understand ➔ Level 10: Final Simulation).
* Interactive timetable generator based on target exam and available daily hours (4h, 6h, 8h, 10h+).

### 10. Progressive Web App (PWA) & Offline Readiness
* `manifest.json` with police emblem badge.
* Service Worker (`sw.js`) caching all static learning modules, syllabi, questions, and flashcards for full offline study.

## 🛠️ Local Development & Scripts

### Prerequisites
* Node.js v18+
* npm v9+

### Setup Instructions
```bash
# Clone the repository
git clone https://github.com/raghavendra-exp/upprpb-master.git
cd upprpb-master

# Install dependencies
npm install

# Run Question Bank Validation Script
node scripts/validate-content.js

# Start local development server
npm run dev

# Build production bundle for GitHub Pages
npm run build
```
